Using it with a class

Before
  1. Sign up and tick I am a teacher.
  2. Dashboard → + New class: you get a code (K7QM-28).
  3. Students sign up with the code (or later: account menu → Join a class).
  4. Everyone in? Switch to Closed to new learners.
During
  1. Students do the 8 exercises, easy to hard (see The 8 exercises).
  2. When a line is wrong, help comes right there. There is no score.
  3. Dashboard → Needs a look: who repeats a mistake, or is still wrong after the answer.
After
  1. Dashboard → Mistakes: the wrong ideas in the class, and which are fixed.
  2. A learner → Details: their answers, line by line.
  3. Google Sheet: every answer, for the analysis.

Try without an account works the same, but the teacher does not see that work.

The idea

1 · Each wrong idea gives its own wrong answer

In a = 1; a = 2; print(a):

  • the answer 1 fits M3
  • 1 2 fits M1
  • 3 fits M2

So the wrong answer itself shows why the student is wrong.

2 · Ask line by line, stop at the first wrong line

  • One question per line.
  • At the first wrong line, the answer is compared with what each wrong idea would answer.

3 · All answers are worked out before the lesson

  • Each wrong idea is a small version of Python that runs the program the wrong way (minterp, made for this project).
  • Every answer of every version is worked out before the lesson.
  • During the lesson, the page only compares the student’s answer with these.

4 · Smaller programs find the part of the line

  • The step where the answers change from correct to wrong shows the problem.
  • It can be the calculation, the names in it, or storing the result (Step back).

5 · Once may be a slip

  • Seen once: in one exercise. It may be a slip.
  • Repeated: seen again, in another exercise or at another kind of line.
  • Fixed: 2 later exercises in a row with a line of the same kind had it correct at the first try. After only one: correct once, 1 more needed.

After a mistake

2a · Practise

Practise this

n = 5 n = 3 * n # what is n now?
  • The student chooses it, at the end of an exercise or in My progress.
  • A new question like the line they got wrong, with new names and numbers.
  • Correct at the first try → one correct for the mistake; 2 in a row → fixed.
2·r · Review

A review, later

x = 4 x = 9 print(x)
  • Comes by itself after the next exercise, for a mistake seen once.
  • It checks the same wrong idea, but on a different kind of line. Example: the mistake was at x = 9; the review asks print(x).
  • No help and no Hint. Wrong → the answer, then the same question again (answer hidden).
  • It shows whether the fix stays.
  • Two different mistakes in exercise 2 → two reviews: 2·r and 2·r2.

My progress

1 ✓2 ✗ → ✓4
  • Each skill: still learning, good or coming up, with its exercises (Ex 3 ✗ Ex 4 ✓).
  • A skill is good when it was never wrong, or the last 2 exercises with it were correct.
  • Each mistake is a card inside its skill, with Practise this.

Final check

  • Comes after the 8 exercises.
  • One more exercise for each wrong idea the 8 exercises could not test, because its question always came after another mistake (all but N2).
  • If no exercise can test it, it is marked not known yet.
  • A wrong idea that was correct only once since the mistake gets one more question here, like a review (no help). Correct → fixed.

Questions

Marks and words

Is there a score?

No. Each exercise gets a mark, as on the Dashboard:

✓correct first tryfixed with help✗wrongnot done

What do seen once, repeated and fixed mean?

The state of a wrong idea (a misconception), on the Dashboard and in the Learner log:

  • seen once: the student showed it in one exercise. It may be a slip.
  • repeated: it showed again, in another exercise or at another kind of line.
  • fixed: 2 later exercises in a row with a line of the same kind had it correct at the first try (with only one: correct once, 1 more needed). The same rule as the skills on the student’s page.
What do correct line by line, correct after Step back, after the Hint, after seeing the answer and still wrong mean?

How an exercise with a wrong line ended, in the Learner log:

  • correct line by line: the output was wrong, but every line was correct when asked one by one.
  • correct after Step back: correct after the smaller programs.
  • correct after the Hint: correct only once the Hint was shown.
  • correct after seeing the answer: correct only after the answer was shown.
  • still wrong: wrong even after the answer.
What is Needs a look, and why is a learner in it?

The box at the top of the Dashboard: the learners you may want to talk to first. Each name comes with its reason, one of two:

  • Same mistake again (ex 2, 5a): the same wrong idea showed in more than one exercise.
  • Wrong after being given the answer (ex 4): the line was still wrong after the page showed the answer.

Being slow or not having started is not a reason.

What does Not explained yet mean?

You see it under Other mistakes (Dashboard → Mistakes, and the Learner log): a wrong answer that none of the 9 wrong ideas explains. When the smaller programs found something, that is shown instead (for example a calculation slip). It is kept so it can be read by hand: a slip, a typo, or a wrong idea that is not on the list.

The exercises

Do all students get the same exercises?

The 8 main exercises, yes, in the same order. Practise questions and reviews come from each student’s own mistakes. The final check comes after the 8 exercises: one more exercise for each wrong idea that the student’s answers have not tested yet. So two students can see different extras.

Can a student see an exercise again, or do it again?

Yes. Click a done exercise: it shows as it was, with the answers and the help. Do it again starts the same exercise from the beginning, but it is not counted again.

What if a student makes a typo?

Extra spaces, commas and quotes are ignored (5,5 = 5 5). Any other typo counts as a wrong answer, but one wrong answer only makes a wrong idea seen once: a single typo never makes it repeated.

Saving

What if a student closes the page or changes computer?

With an account, the work is saved after each exercise, and the student goes on from any computer. With Try without an account, it stays only in that browser. An exercise not finished starts again from the beginning.

For the teacher

What is the Test view?

A view for the teacher and for checking the design, opened from the small Test view link at the bottom of Exercises (teacher accounts only). It shows the codes (M1, X19…) and an Answer as row that types the answers of a chosen wrong idea, so a whole session can be tried without typing.

For checking the design

How the bank exercises are made

1. Templates with blanks

11 templates, 3 to 6 lines, such as {v} = {n1}; {v} = {n2}; print({v}) (Kumar, 2005).

2. Filling the blanks

Names from 10 neutral words (total, count, score, price, age, size, level, points, steps, speed), so learners cannot guess from the name. Numbers 1 to 9, all different, so the arithmetic is easy.

3. Two checks

Kept only if each target wrong idea makes the output wrong, and no other wrong idea gives the same wrong output. Otherwise drawn again.

4. A fixed bank

5 exercises per template, 55 in all, saved in a file that can be checked before the lesson. The next extra exercise uses another template when it can; a learner never meets the same exercise twice.
